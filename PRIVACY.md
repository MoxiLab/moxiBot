# Política de Privacidad de Moxi

Última actualización: 16-02-2026

## 1) Qué datos procesa el bot

Moxi procesa solo datos necesarios para funcionar dentro de Discord, por ejemplo:

- IDs de servidor/canal/usuario para ejecutar comandos y configuraciones.
- Configuración del servidor (prefijo, idioma, módulos activados).
- Datos funcionales de módulos (por ejemplo: economía, AFK, verificaciones, auditoría) cuando están habilitados.
- Métricas técnicas básicas de uso para estabilidad y diagnóstico.

Moxi **no solicita** contraseñas ni tokens de cuentas de usuario.

## 2) Para qué se usan

Los datos se usan para:

- Proveer funciones del bot solicitadas por administradores/usuarios.
- Mantener configuración persistente entre reinicios.
- Moderación, seguridad y prevención de abuso en el servidor.
- Diagnóstico técnico y mejora de estabilidad.

## 3) Compartición de datos

- No se venden ni se comercializan datos de Discord.
- No se comparten datos con redes publicitarias ni brokers de datos.
- Solo se comparten con proveedores técnicos necesarios para operar el bot (hosting/base de datos), bajo controles razonables.

## 4) Conservación

Los datos se conservan mientras sean necesarios para la funcionalidad del bot o por obligaciones legales aplicables.
Cuando dejen de ser necesarios, se eliminan o anonimizan en la medida de lo razonable.

## 5) Solicitudes de acceso/borrado

Puedes solicitar borrado o revisión de datos usando los comandos:

- `privacy`
- `/privacy`

Contacto de borrado/configuración (si existe): variable `DATA_DELETE_CONTACT` en entorno.

## 6) Seguridad

Se aplican medidas técnicas y organizativas razonables para proteger los datos frente a acceso no autorizado.

## 7) Cambios en esta política

Esta política puede actualizarse. Se recomienda mantener el enlace público actualizado en el Developer Portal de Discord (`PRIVACY_POLICY_URL`).
